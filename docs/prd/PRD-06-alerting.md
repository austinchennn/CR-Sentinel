# PRD-06：告警通知

## 目标

高危攻击判定后，除了自动处置，还要有人工兜底的通知渠道，完成"AI 自动防御 + 人工可感知"的闭环，也是 rawmaterial 里明确提到的能力点。

## 范围

- SNS Topic 配置（邮件订阅）
- Lambda 侧在写 `alert_log` 后触发 SNS 推送
- 告警内容格式化（IP、风险等级、攻击类型、处置动作、时间）

## 非目标

- 不做短信/企业微信等多渠道（时间有限，先把邮件这一条链路做扎实，其他渠道只在 README 里提一句"可扩展"）

## 功能需求

1. 创建 SNS Topic，订阅团队邮箱
2. PatrolAgentLambda 在写入 `alert_log`（`severity = high`）后，同步发布一条 SNS 消息
3. 消息内容包含：攻击 IP、风险等级、攻击类型、AI 推理摘要、已执行的处置动作、时间戳，格式清晰可读（邮件正文即可，不需要额外模板引擎）
4. `alert_log.sent` 字段在推送成功后更新为 `true`，避免重复推送（幂等）

## 用到的 CockroachDB & AWS 工具

- **CockroachDB**：`alert_log` 表读写
- **AWS**：SNS

## 验收标准

- [ ] 触发一次高危判定后，订阅邮箱能收到对应告警邮件
- [ ] 邮件内容包含完整关键信息，不需要再查库就能理解发生了什么
- [ ] `alert_log.sent` 正确更新，重复跑巡检不会对同一事件重复推送
